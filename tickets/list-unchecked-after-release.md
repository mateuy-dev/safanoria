## Objective

Provide one CLI command that lists the text of every unchecked After Release item across tickets alongside its ticket ID. Include items still waiting for a release and distinguish them from tasks already due using the existing component stamp rules. Today list --after-release shows only ticket IDs and titles for work due now, so someone looking for all outstanding tasks must open individual files. Omit checked items and make an empty result clear.
